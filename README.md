# decMHT

Project page for "Learning Multi-Humanoid Pickup and Transport via Decentralized Object-Centric Control" (under review).

## Adding media

- Videos: drop `.mp4` files into `static/videos/` and update the placeholder `<div>` blocks in `index.html` (marked with `TODO` comments) with `<video>` tags, following the pattern used on [decplm.github.io](https://decplm.github.io).
- Images/figures: drop image files into `static/images/` and update the placeholder blocks similarly.
- Once a public arXiv/PDF link, code repo, or video is available, update the `publication-links` block in the hero section (commented-out buttons are provided as a starting point).

## Local preview

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
